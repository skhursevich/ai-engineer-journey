# AI Engineer Journey

Публичный лог обучения Frontend → AI Engineer: конспекты, решённые задачи, итоговые проекты по каждой фазе.

## Структура

- `notes/` — еженедельные конспекты (что изучено, какие ресурсы, какие задачи решены)
- `projects/` — итоговые проекты фаз (появятся по ходу обучения)

## Фазы

0. Подготовка — окружение, аккаунты, репозиторий
1. Python — синтаксис, экосистема, тесты, FastAPI
2. LLM / Prompt Engineering — токены, cookbook'и, structured outputs
3. RAG — embeddings, chunking, векторные базы
4. Агенты / MCP — function calling, ReAct, LangGraph
5. Продакшн / LLMOps — наблюдаемость, деплой
6. Портфолио / поиск работы

## Прогресс

См. `notes/` — конспект заводится на каждую неделю.
